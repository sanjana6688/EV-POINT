EV POINT – EV Charging Station Booking Web App

EV POINT is a web application that helps users find and book EV charging stations. Users can search for stations, view their locations on an interactive Leaflet.js map, and manage bookings through a user dashboard. Administrators can manage stations, users, and bookings through a separate admin dashboard.

Features

- User registration, login, logout, and forgot password
- Search and book EV charging stations
- Cancel bookings and manage user profile
- Interactive station map using Leaflet.js
- User and admin dashboards
- Role-based access control and input validation
- CRUD operations backed by MySQL
- Home, About Us, and Contact pages

Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python, Flask
- Database: MySQL
- Maps: Leaflet.js
